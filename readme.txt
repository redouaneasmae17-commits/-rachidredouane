موقع رشيد رضوان — نسخة أولية جاهزة للتشغيل

محتويات الحزمة:
- index.html: واجهة الموقع الرئيسية.
- style.css: التصميم والألوان والتجاوب مع الهاتف.
- script.js: الأقسام العلمية ولوحة التحكم وإدارة الدروس.

طريقة التشغيل:
1) فك ضغط الملف.
2) افتح index.html باستخدام متصفح حديث (Chrome أو Edge أو Firefox).
3) اضغط "لوحة التحكم" لإضافة درس.
4) من "نسخ احتياطي" صدّر ملف JSON للاحتفاظ بالدروس أو نقلها.

مهم:
هذه نسخة موقع ثابتة (Static Website) قابلة للرفع إلى استضافة تدعم HTML/CSS/JS.
لوحة التحكم في هذه النسخة تحفظ الدروس محلياً داخل المتصفح والجهاز الحالي فقط؛ لا توجد قاعدة بيانات أو تسجيل دخول أو رفع مركزي للملفات. لذلك فإن نشرها على الإنترنت لا يجعل إضافات لوحة التحكم مشتركة بين الزوار أو الأجهزة.
لتحويل لوحة التحكم إلى نظام نشر حقيقي متعدد الأجهزة، يلزم ربطها بخادم وقاعدة بيانات وتسجيل دخول آمن وتخزين ملفات (مثل Supabase أو Firebase أو backend خاص).
لا تضع كلمات مرور أو بيانات حساسة في هذه النسخة.
